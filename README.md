# 🔤 English Grammar Trainer

小六英文文法練習 app，分主題訓練。

## 練習主題

1. **Look and Write: 看圖寫作** — 用簡單句子描述圖片
2. **Grammar 1: so (原因和結果)** — 用 so 連接因果句子
3. **Grammar 2: who / which (關係代詞)** — 用 who 指人，which 指物
4. **Connectives: so / so that / because** — 分辨連接詞用法
5. **Adverbs: 副詞 (方式 + 頻率)** — 學習方式副詞同頻率副詞

## 使用方法

1. 選擇練習主題
2. 展開題目作答
3. 檢查答案同解釋
